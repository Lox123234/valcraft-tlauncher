# Диагностика ValCraft TLauncher Setup

[← README](../README.md) · [← Туториал](TUTORIAL.md)

## С чего начать

Запустите `CHECK.cmd`, затем откройте окно, в котором возникла ошибка. После этого найдите журналы Minecraft и Valheim. При публикации лога в GitHub Issues **удалите личные пути, имена учётных записей, IP-адреса и токены**.

| Симптом | Что проверить |
|---|---|
| `Valheim executable missing` | Найден ли `valheim.exe`, верен ли `-ValheimPath` |
| `TLauncher executable missing` | Верен ли `TLauncher.exe`, укажите `-TLauncherPath` при установке |
| `existing BepInEx installation is missing` | Должен существовать `Valheim\BepInEx\core\BepInEx.dll` |
| `Java` / неподходящая версия | В TLauncher выберите профиль ValCraft и Java **25** |
| `Minecraft did not start within 30 minutes` | Запущен ли правильный профиль, открылся ли локальный мост TCP `25599`, смотрите `latest.log` |
| Нет блоков Minecraft | Запуск Valheim через DirectX 11 (`-force-d3d11`), файл `ReShade.log`, клавиша **F7** |
| `Missing files` | Верните целостную распаковку и повторите `INSTALL.cmd` после проверки причин |
| `Checksum mismatch` | Неполная загрузка или несовпадение контрольной суммы; проверьте соединение и повторите попытку |
| `Folder moved` | После переноса директории повторите `INSTALL.cmd` и обновите пути |
| `Access denied` | Проверьте права на папку Valheim; при необходимости запустите INSTALL от администратора |
| Valheim не запускается | Проверьте конфликты `dxgi.dll`, BepInEx и других модов; при необходимости выполните `RESTORE.cmd` |

## Где находятся логи

```text
<папка репозитория>\runtime\minecraft\logs\latest.log
<папка Valheim>\BepInEx\LogOutput.log
<папка Valheim>\ReShade.log
```

## Важные ограничения

- `CHECK.cmd` проверяет наличие и некоторые хеши компонентов, но не производительность или совместимость.
- `START.cmd` должен увидеть процесс Minecraft ValCraft с прослушивающим TCP-портом `25599`, иначе Valheim автоматически не стартует.
- ReShade требует DirectX 11; Vulkan не подходит для этой интеграции.
- Скрипт установки Valheim не заменяет `dxgi.dll`, если он уже существует. Если у вас был другой ReShade/оверлей, сначала выясните, совместим ли он с ValCraft; не удаляйте чужие файлы без копии.
- Моды и сохранения других сборок могут быть несовместимы с экспериментальным ValCraft.

## Как оформить сообщение об ошибке

Укажите версию Windows, путь установки Valheim (без личных данных), версию Java, этап `INSTALL`/`START`/`CHECK`, текст ошибки и последние релевантные строки журналов. Напишите, повторяется ли ошибка на новом мире без сторонних модов. **Не выкладывайте личные сохранения или всё содержимое `runtime/` в открытый доступ.**
