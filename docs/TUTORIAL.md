# ValCraft + TLauncher — подробный туториал

[← Вернуться к README](../README.md)

В этой инструкции показано, как подготовить Valheim, создать профиль Minecraft через установщик и запустить оба процесса. Описывается именно **TLauncher-адаптация**; оригинальный ValCraft использует Prism Launcher.

## 1. Подготовка

Перед установкой проверьте:

- Windows 10 или 11, рабочий Valheim и доступ к Minecraft Java Edition.
- Установленный TLauncher. Точный путь к `TLauncher.exe` понадобится при нестандартной установке.
- Установленный BepInEx для Valheim. Файл `BepInEx\core\BepInEx.dll` должен существовать.
- Интернет для скачивания Minecraft 26.3, Java 25, Fabric API, ReShade и вспомогательных файлов.
- Свободную оперативную память для Valheim и отдельного процесса Minecraft; Minecraft получает лимит `-Xmx4096M`.

Создайте **резервную копию сохранений Valheim**. Для первой проверки лучше использовать новый игровой мир.

## 2. Распаковка

Скачайте репозиторий через **Code → Download ZIP** и распакуйте, например, в `D:\Games\ValCraft-Setup`. Откройте папку, в которой расположены `INSTALL.cmd`, `START.cmd` и `ValCraft-TLauncher.ps1`. Не копируйте только `.cmd` файлы: они используют PowerShell-сценарий и `upstream/files/`.

## 3. Установка

Закройте TLauncher, Minecraft и Valheim. Запустите **`INSTALL.cmd`**.

Скрипт проверяет существование игр и BepInEx, создаёт версию **`ValCraft-26.3-Fabric`** в каталоге TLauncher и отдельную рабочую папку Minecraft `runtime\minecraft`. Для Minecraft устанавливаются Fabric Loader 0.19.5, Fabric API и компонент ValCraft. Для Valheim добавляются плагин BepInEx, эффект ReShade и надстройка ValCraft.

Для установки нужна запись в папку Valheim. Если Windows выдаёт отказ в доступе, запустите **только `INSTALL.cmd` от имени администратора** после проверки источника скриптов. При неполной установке прочитайте текст ошибки и исправьте проблему перед повторной попыткой.

## 4. Нестандартные пути к играм

По умолчанию сценарий ищет:

| Что | Путь |
|---|---|
| Valheim | `C:\Program Files (x86)\Steam\steamapps\common\Valheim` |
| Каталог Minecraft | `%APPDATA%\.minecraft` |
| TLauncher | `%APPDATA%\.minecraft\TLauncher.exe` |

Если игра находится в другом каталоге, запустите PowerShell в папке репозитория и укажите собственные пути:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\ValCraft-TLauncher.ps1 `
  -Action Install `
  -ValheimPath 'D:\SteamLibrary\steamapps\common\Valheim' `
  -MinecraftPath "$env:APPDATA\.minecraft" `
  -TLauncherPath 'D:\Launchers\TLauncher.exe'
```

Пути выше **только примеры**. Указывайте реальные пути, где находятся `valheim.exe`, каталог `versions` Minecraft и `TLauncher.exe`. Успешная установка сохраняет их в `valcraft.local.json`, поэтому в следующий раз можно использовать обычные `.cmd` файлы. Этот файл скрыт от Git с помощью `.gitignore`.

## 5. Первый запуск

1. Запустите **`START.cmd`**.
2. Дождитесь появления окна TLauncher. Если TLauncher уже открыт, найдите его вручную.
3. В выборе версии укажите **`ValCraft-26.3-Fabric`**, а не обычную версию Minecraft или другую сборку.
4. Нажмите **запуск Minecraft** в TLauncher. Автоматическое нажатие этой кнопки скриптом не предусмотрено.
5. При первом запуске лаунчер может загрузить **Java 25**, библиотеки и ресурсы. Не закрывайте окно `START.cmd`.
6. Когда Minecraft запустит локальный мост ValCraft, сценарий автоматически откроет Valheim с аргументом `-force-d3d11`.
7. Проверьте интеграцию на новом мире Valheim, переключаясь клавишей **R**.

Ожидание Minecraft ограничено **30 минутами**. Если на этом этапе возникла ошибка, диагностика доступна в [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## 6. Первые действия в игре

**Управление Minecraft:** клавиша **R** переключает режимы. Через **E** откройте инвентарь. Выберите блок в панели `1–9`, установите его **ПКМ** или разрушьте/атакуйте **ЛКМ**. Используйте **F5**, чтобы поменять ракурс. Режим Minecraft влияет на то, какие действия выполняются обычным управлением Valheim.

**Творческий режим:** **F9** переключает выживание и творческий режим; в творческом доступен полёт двойным нажатием пробела. При необходимости клавишами **F7** включайте или выключайте интеграцию и **F8** выравнивайте сетку блоков.

**Возврат к Valheim:** снова нажмите **R**. Вы сможете пользоваться привычным инвентарём, оружием и действиями персонажа Valheim.

## 7. Проверка целостности

Запустите **`CHECK.cmd`** после установки или при подозрении на повреждение файлов. Утилита проверяет наличие необходимых компонентов, совпадение хешей некоторых файлов и ожидаемые свойства профиля TLauncher. Это статическая проверка: **она не заменяет реальный игровой тест**.

## 8. Как безопасно откатить изменения

Закройте TLauncher, Minecraft и Valheim. Запустите **`RESTORE.cmd`**. Сценарий использует содержимое `backup-before-valcraft/` для восстановления изменённых файлов Valheim. Он **не удаляет** созданный мир Minecraft и скачанные файлы.

Не удаляйте `backup-before-valcraft` до отката. Если папка установки перенесена после первоначальной установки, снова запустите `INSTALL.cmd` для обновления локальных путей (после проверки своих резервных копий).

## 9. Что не делает сборка

- Не устанавливает Valheim или лицензию Minecraft.
- Не устанавливает BepInEx с нуля.
- Не гарантирует работу с другими модами Valheim.
- Не запускает Minecraft без участия пользователя в интерфейсе TLauncher.
- Не заменяет официальную поддержку Minecraft, Fabric, ReShade или разработчиков ValCraft.
